Credits and sources

Film release dates are provided by TMDB (The Movie Database). Television season premieres are provided by TVmaze.

This product uses the TMDB API but is not endorsed or certified by TMDB.

TVmaze data is credited to TVmaze and used under its CC BY-SA API licence. Source links are included in individual RSS items.

The feed originally used Releases.com. In November 2026, GitHub Actions requests received HTTP 403 responses from the site, so the project migrated to the documented TMDB and TVmaze APIs without bypassing those restrictions. Read the project history.

The public feed is usable worldwide, but movie release dates and broadcast schedules default to the US; web/streaming premieres may be international. See the README for configuration details.

The TMDB logo is linked from TMDB's own officially published SVG asset. See TMDB's branding and attribution requirements.
